Site nav — thin, wide-tracked, no logo mark (the wordmark is set type).

```jsx
<SiteNav transparent align="center" wordmark="Styling OC"
  links={[{label:'Interiors',href:'/interiors'},{label:'Personal Styling',href:'/styling'},{label:'Projects',href:'/projects'},{label:'Studio',href:'/studio'}]}
  cta={{label:'Inquire',href:'/inquire'}} />
```

Use `transparent` only above a full-bleed hero. `align="left"` for interior pages.
