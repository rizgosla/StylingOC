Bordered rectangular CTA — use for the single primary action in a section (inquire, view services); never more than one per viewport.

```jsx
<Button href="/inquire">Begin an inquiry</Button>
<Button variant="onImage" size="lg">View the project</Button>
```

Variants: `outline` (default, fills with ink on hover), `solid` (rare), `onImage` (over photography). Sizes sm/md/lg. Never add icons, fills, or radii above 2px.
