Full-bleed hero — the opener for every page. Type sits on the image, centered, over the scrim; never in a card.

```jsx
<EditorialHero image="/assets/images/interior-pool-view.jpeg" imageAlt="Living room opening onto a pool courtyard"
  eyebrow="Interior Design · Orange County" headline="Design that feels like home."
  sublines={["A thoughtful collaboration. A beautiful transformation."]}
  caption="Newport Coast residence" />
```

`meta` adds the scope row used on project openers. Pair with `<SiteNav transparent />`. Headline stays under about seven words.
